# Дорожная карта: «Пасьянс-путешествие»

Цель релиза — пройти модерацию с первого-второго раза и **не упасть ниже рейтинга 30** (правило 2.13, см. `docs/market-research.md`). Поэтому этапы 5–6 весят не меньше, чем ядро.

## Этап 0. Подготовка репозитория — неделя 1

- [x] Phaser 4 (4.2.1) + TypeScript + Vite, `npm run build` собирает `dist/`
- [x] `index.html` с подключением `/sdk.js`, относительные пути (`base: './'`)
- [x] Обёртка SDK с моками: игра запускается без YaGames (`src/yandex/sdk.ts`)
- [x] Структура `docs/`: исследование, GDD, чек-лист требований, арт-доки
- [x] CI-сборка (GitHub Actions) + проверка лимита 100 МБ и имён файлов (`npm run check:size`)
- [ ] Подключить `@yandex-games/sdk-dev-proxy` в ежедневный цикл (`npm run dev:yandex`), проверить моки рекламы/авторизации/сохранений
- [ ] Уточнить команду и параметры dev-proxy по актуальной документации [10]

## Этап 1. Ядро пасьянса — недели 2–3

- [x] **Играбельный прототип** (2026-10-18, внепланово для ручной проверки): 28 карт, правило ±1, колода/сброс, победа/поражение, «Новая игра» — всё в `GameScene`, генератор цепочкой ±1 гарантирует существование решения
- [x] Модель TriPeaks вынесена в `src/game/tripeaks.ts` (без Phaser), сцена только рисует
- [ ] Генератор раскладок **обратной конструкцией**: сначала строится решение, из него — раскладка ⇒ каждый уровень гарантированно проходим
- [ ] Открытие закрытых карт при снятии перекрывающих; серия (стрик) и счёт
- [ ] Условия победы/поражения, пересдача
- [x] Юнит-тесты генератора (vitest, в CI): 1000 сидов = 1000 проходимых партий, решение проигрывается через replaySolution
- [ ] Базовый UI: крупные карты, тап-цели ≥ 44px (аудитория 45+)

## Этап 2. Арт и стиль — недели 3–4

- [ ] Сгенерировать карты (рубашка, фон карт), фоны регионов, иконки по `docs/art/prompts.md`
- [ ] Каждый ассет: промпт, модель, seed — записаны в `docs/art/prompts.md` (ИИ-материалы допустимы, интерактивный ИИ — нет)
- [ ] Проверка читаемости рангов на реальном телефоне при ярком свете
- [ ] Все имена файлов — латиница без пробелов (проверяется `check:size`)

## Этап 3. Мета и прогресс — недели 5–6

- [ ] Карта путешествия: регионы с разным оформлением, звёзды за уровни (1–3)
- [ ] Кривая сложности: больше рядов → закрытые карты → замки → карты-препятствия
- [x] Монеты и звёзды за уровень, счёт и серии (первая версия меты в прототипе)
- [ ] Бустеры (отмена хода, +5 карт, дикая карта)
- [ ] Ежедневный бонус, коллекции
- [x] Сохранения прогресса (уровень/звёзды/монеты): `player.setData` + localStorage-фолбэк
- [ ] Сохранение незаконченной партии после перезагрузки

## Этап 4. SDK и монетизация — неделя 7

- [ ] `LoadingAPI.ready()` ровно в момент готовности (уже в BootScene — перепроверить после прелоада ассетов)
- [ ] GameplayAPI start/stop на старте/конце уровня
- [ ] Rewarded: +5 карт, отмена хода, удвоение монет — **только бонусы** (п. 4.5.2)
- [ ] Interstitial между уровнями: игра и звук на паузе
- [ ] Инапы: наборы монет, бустеры, «без межстраничной рекламы»; обязательное консумирование покупок
- [ ] Авторизация только по кнопке, гостевой вход всегда доступен
- [ ] i18n ru/en, язык — через SDK (`environment.i18n.lang`)
- [ ] Звук на паузу при потере фокуса (BLUR/FOCUS уже в `main.ts` — проверить со звуковыми ассетами)

## Этап 5. Полировка и модерация — неделя 8

- [ ] Промоматериалы: иконка, скриншоты, описание ru/en; основное содержание > 10 минут
- [ ] Отправка на модерацию
