# Девлог — день 1 (2026-10-18)

## Что сделано

- Зафиксировано исследование рынка Яндекс Игр (октябрь 2026) → `docs/market-research.md`. Ключевые выводы: аудитория 45+ и хитовый карточный жанр аргументируют пасьянс; главный риск — не конкуренция, а снятие по правилу 2.13 (рейтинг ≤30 три недели) и 72% отказов модерации по UI/SDK/технике.
- Выбрана концепция «Пасьянс-путешествие»: TriPeaks, процедурные гарантированно проходимые уровни, карта путешествия, гибридная монетизация (rewarded только бонусами) → `docs/gdd.md`.
- Стех: Phaser 4.2.1 + TypeScript + Vite (вес ~500 КБ против 8–9 МБ у Godot/Unity — первая минута решает).
- Скелет репозитория:
  - `index.html` с подключением `/sdk.js`;
  - обёртка SDK с моками (`src/yandex/sdk.ts`): игра стартует без YaGames, `LoadingAPI.ready()`, сохранения `player.setData` + localStorage, rewarded/fullscreen с колбэками;
  - заглушка `GameScene` с силуэтом раскладки TriPeaks;
  - звук на паузу при потере фокуса;
  - CI (GitHub Actions) + `npm run check:size`: `index.html` в корне dist, ≤100 МБ, без пробелов/кириллицы в именах.
- Документы: роадмапа с чекбоксами, чек-лист требований к модерации (разделы 1–9 закрывать целиком перед подачей), стиль-гайд и журнал промптов арта.

## Решения и почему

- **Обратная конструкция генератора** (сначала решение, потом раскладка): каждый уровень проходим по построению — это страховка рейтинга и, значит, жизни игры на платформе.
- **Моки SDK с первого дня:** 72% отказов — техника; SDK-интеграция не должна быть «предрелизной неделей».
- **`base: './'` в Vite:** архив Яндекса открывается не из корня домена, абсолютные пути убили бы сборку.

## Добавлено в тот же день: играбельный прототип

По запросу «как играть и проверить» заглушка `GameScene` заменена рабочим прототипом TriPeaks: 28 карт по геометрии 3 пиков, закрытые карты открываются при снятии перекрывающих, правило ±1 по кругу, колода/сброс, победа/поражение, рестарт. Генератор цепочкой ±1 гарантирует существование решения (карты раскладки и колоды назначаются по одной цепочке в допустимом порядке снятия). Это прототип для ручной проверки, а не финальное ядро: вынос в модуль и юнит-тесты остаются в этапе 1.

## Вечер: раскладка и рубашки

По обратной связи («кучноваты карты») раскладка переразведена: карты 64×92, шаг 67px на всю ширину поля, перекрытие рядов ~14px, декоративная рамка стола. Сгенерированы и выбраны пользователем три рубашки («Бордо», «Солнце», «Сакура»), обрезаны до 256×368 и встроены: закрытые карты и колода показывают рубашку, выбор переключается кнопками и запоминается.

## Вечер-2: поле на весь экран

По скриншоту пользователя: поле было мелким и карты перекрывались. Раскладка переделана без перекрытий (62×100, зазоры 7×12px, верхняя карта ровно между двумя нижними), холст укорочен до 720×1120, чтобы Phaser FIT не упирался в высоту, колода/сброс увеличены, контролы распределены до низа экрана.

## Вечер-3: фикс «взрыва» рубашек

Пользователь поймал баг: при переключении на «Солнце» карты раздувались на пол-экрана. Причина: файл back-travel остался исходником 2048×2048 (остальные 256×368), а Phaser при setTexture сохраняет масштаб от старой текстуры. Лечение: файл обрезан до 256×368, а в код добавлен applyBack() — после каждой смены текстуры размер выставляется заново.

## Вечер-4: ядро вынесено, тесты, первая мета

По команде «идём дальше»: генератор и правила переехали из сцены в чистый модуль `src/game/tripeaks.ts` с детерминированным RNG; vitest проверяет 1000/1000 проходимых партий (решение честно проигрывается правилами игры), тесты добавлены в CI. Сверху — первая мета: уровни (после победы кнопка ведёт на следующий), звёзды по остатку колоды, монеты, счёт и серии, флип-анимация открытия карт. Прогресс (уровень/звёзды/монеты) сохраняется через обёртку SDK и переживает перезагрузку.

## Вечер-5: адаптивная вёрстка, HUD, настройки

По скриншоту: поле мелкое, HUD хаотичен, рубашки занимают экран. Сделан редизайн: Scale.EXPAND + layout() от фактического размера окна (карты считаются по ширине поля), тёмная HUD-панель сверху (уровень пилюлей, звёзды/монеты, шестерёнка), счёт/серия отдельной строкой. Рубашки уехали в модальные настройки (⚙): превью трёх рубашек, звук, сброс прогресса. Новая игра и подсказки остались под полем.
