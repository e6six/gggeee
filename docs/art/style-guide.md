# Стиль-гайд: «Пасьянс-путешествие»

Аудитория 45+ диктует стиль сильнее вкуса: **читаемость важнее декоративности**. Все ассеты — заранее сгенерированные ИИ-материалы (допустимы платформой); интерактивного ИИ в игре нет. Каждый ассет записывается в `docs/art/prompts.md`.

## 1. Принципы

1. **Карта читается за полсекунды:** крупный ранг в двух углах, масть большой пиктограммой, ничего поверх ранга.
2. **Контраст:** тёмный стол, светлые карты; красное/чёрное различается и без цвета (форма масти).
3. **Никакого мелкого текста в арте:** весь текст рисует код (Phaser Text), не генератор изображений — генератор искажает буквы.
4. **Тёплая «путешественническая» тема:** карта мира, открытки, почтовые марки; без агрессивного неона гиперкэжуала.

## 2. Палитра

| Роль | Цвет | Использование |
|---|---|---|
| Стол / фон | `#10251c` глубокий зелёный | базовый фон (совпадает с `main.ts`) |
| Карта (лицо) | `#f7f1de` тёплый белый | фон карт |
| Карта (рубашка) | `#8f2f2f` бордовый + золотой узор | рубашка |
| Акцент | `#f0c94a` золотой | кнопки, звёзды, награды |
| Текст на тёмном | `#f5e9c9` | заголовки |
| Вторичный текст | `#b9d3a8` | подписи |
| Красные масти | `#b03030` | черви/бубны |
| Чёрные масти | `#20301f` | пики/трефы |

Фоны регионов меняют оттенок стола и декор, но **не** цвета карт и акцентов — узнаваемость механики важнее разнообразия.

## 3. Карты

- Пропорции 5:7, скругление ~13% ширины, тонкая тёмно-зелёная обводка.
- Ранг: кегль ≥ 28% высоты карты в игровом размере; масть под рангом и крупная в центре.
- Закрытая карта: рубашка с золотой каймой — состояние «закрыто» должно считываться мгновенно.
- Замок/лёд: иконка поверх центра карты, ранг остаётся видимым.

## 4. Регионы (этапы путешествия)

Пустыня с пирамидами → Пагода у осенней горы → Башня над водопадом → Зелёные горы и озеро (по островам карты мира). На локацию: фон стола, открытка в коллекцию. Декор — по краям поля, центр стола всегда чистый. У каждого фона есть три варианта под форму экрана: портретный, wide 1920×1080 и tall 1080×1920 (зеркальное достраивание, `scripts/make-bg-variants.py`). Игра выбирает вариант по окну и показывает cover-ом — декор по краям не обрезается и картинка не выглядит склеенной из кусков разного масштаба.

## 5. UI

- Кнопки: золотой фон, тёмный текст, высота ≥ 48px, скругление 12px.
- Иконки бустеров: одна метафора на бустер (стрелка назад = отмена, колода «+5», звезда = дикая карта), без текста на иконке.
- Анимации: 150–250 мс, карты «летят», но не вращаются в 3D — спокойный темп для аудитории.

## 6. Запрещено

- Мелкие узоры под рангом, полупрозрачные карты, текст, сгенерированный внутри картинки.
- Чужие товарные знаки и стилизация под конкретные чужие карточные игры.
- Файлы с пробелами/кириллицей в именах (техническое требование платформы).
